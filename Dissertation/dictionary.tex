\chapter*{Словарь терминов}             % Заголовок
\addcontentsline{toc}{chapter}{Словарь терминов}  % Добавляем его в оглавление

\textbf{CEM} : Cross-Entropy Method, метод кросс-энтропии

\textbf{CMDP} : Constrained Markov Decision Process, марковский процесс принятия решений с ограничениями

\textbf{CPO} : Constrained Policy Optimization, оптимизация стратегии с ограничениями

\textbf{CR} : Collision Rate, частота столкновений

\textbf{GCRL} : Goal-Conditioned Reinforcement Learning, обучение с подкреплением, обусловленное целью

\textbf{HER} : Hindsight Experience Replay, переиспользование опыта с переобозначением цели

\textbf{HRL} : Hierarchical Reinforcement Learning, иерархическое обучение с подкреплением

\textbf{ITES} : Imagine To Ensure Safety, метод безопасного иерархического обучения с использованием модели мира

\textbf{LLM} : Large Language Model, большая языковая модель

\textbf{MBRL} : Model-Based Reinforcement Learning, обучение с подкреплением на основе модели мира

\textbf{MCTS} : Monte-Carlo Tree Search, поиск по дереву методом Монте-Карло

\textbf{MDP} : Markov Decision Process, марковский процесс принятия решений

\textbf{MFRL} : Model-Free Reinforcement Learning, обучение с подкреплением без модели мира

\textbf{MPC} : Model Predictive Control, управление с предсказанием модели

\textbf{MTSC} --- Mean Total Safety Cost, средний накопленный штраф безопасности за эпизод

\textbf{PPO} : Proximal Policy Optimization, метод оптимизации стратегии с ограничением шага обновления

\textbf{RQ} : Research Question, исследовательский вопрос

\textbf{SAC} : Soft Actor-Critic, актор-критик метод с энтропийной регуляризацией

\textbf{Safe RL} : Safe Reinforcement Learning, безопасное обучение с подкреплением

\textbf{SG-Safe} : Subgoal-Guided Safe Reinforcement Learning, безопасное обучение с подкреплением с направлением через подцели

\textbf{SPOWL} : Safe Planning and Policy Optimization via World Model Learning, безопасное планирование и оптимизация стратегии с использованием модели мира

\textbf{SR} : Success Rate, доля успешных эпизодов

\textbf{TD-MPC} : Temporal Difference Learning for Model Predictive Control, обучение временных разностей для управления с предсказанием модели

\textbf{TD3} : Twin Delayed Deep Deterministic Policy Gradient, метод детерминированного градиента стратегии с двумя критиками и задержанным обновлением

\textbf{VLM} : Vision-Language Model, визуально-языковая модель
